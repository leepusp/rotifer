# Security policy

## Supported versions

Only the latest version on the `master` branch is supported. No released branches are maintained separately.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately with GitHub private vulnerability reporting: open the repository's Security tab and choose "Report a vulnerability".

Include:

- the ROTIFER version or commit you used
- the steps needed to reproduce the problem
- the expected and the actual behaviour
- the impact you think it has, and any proof of concept

## What to expect

- We will acknowledge your report within 7 days.
- We will then send updates as the fix progresses.
- After a fix is merged, we will disclose the issue publicly and credit the reporter if they wish.
