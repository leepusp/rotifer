# Contributing

This section is for anyone who writes ROTIFER code or improves this
site: laboratory members documenting their own modules, and outside
contributors sending patches.

- {doc}`documentation/index` covers writing docstrings, building the
  site locally, the design system that keeps it consistent, and a
  FAQ on which file controls which part of the site.
- {doc}`changelog` says when a pull request needs a changelog entry
  and how to write one.
- {doc}`releasing` is the release checklist for maintainers.
- {doc}`adr` says which changes need an architecture decision record
  and what it must contain.
