## Stack

The site is the existing Sphinx documentation (MyST Markdown, Shibuya theme) in `docs/`, published at https://leepusp.github.io/rotifer/. The new landing page lives inside this Sphinx site as a custom index page, so there is still one build and one deploy (decided 2026-11-17). This file and DESIGN.md live in `docs/design/`, which `docs/conf.py` excludes from the build.

## Users

The primary audience for the landing page and the README is external researchers: computational biologists outside LEEP who are deciding whether to adopt rotifer for comparative genomics work (confirmed 2026-11-17). Lab members and collaborators also use the docs, but the landing page and README are written for the newcomer.

## Product Purpose

ROTIFER (Rapid Open-source Tools and Infrastructure For data Exploration and Research) is a multi-language collection of high-level libraries for building data analysis pipelines in comparative genomics and the computational analysis of biological sequences, plus command-line tools built on that framework. The Python package lives in `lib/rotifer`; the command-line tools are in `bin/`.

The rebrand gives rotifer a simple visual identity, a redesigned website with a real landing page, and a README that is easier to read. Success means an external researcher understands within one screen what rotifer does, sees that it covers their kind of work, and knows how to install it and where the docs are.

## Positioning

The landing page leads with three capabilities, all of which exist in the repository today (confirmed 2026-11-17):

1. Database cursors (`rotifer.db`): fetching from NCBI, UniProt and local mirrors at scale, such as identical protein groups (IPGs), assembly reports and taxonomy.
2. Genomic context: gene neighbourhoods and operons (`acc2operon`, `neighborhood_explorer`, `neighborhood2svg`, `operon2table`).
3. Domains and alignments: domain architectures and parsers for search and alignment output (`hmmer2table`, `hhsuite2table`, `domain2architecture`, the `aln*` tools).

The pipeline framework (the libraries as a base for your own pipelines) is real but not a lead message.

## Operating Context

- Rotifer has been developed since 2019, mostly at LEEP (psel), with more than eight contributors.
- Installation today means cloning the repository and creating a conda environment with the listed dependencies (see README.md and `docs/install.md`, which show the same commands). There is no PyPI or Bioconda package. The site and README must not promise a one-line install that does not exist.
- Three README install commands were corrected on 2026-11-17 (`touch` paths under `$CONDA_PREFIX`, `cpan -i`, the leading slash in the `PATH` export). A lab member is asked to confirm them on the PR.
- The docs already have sections for Data access (`docs/db/`), the API reference (`docs/api/`), Contributing and License.
- Licence: BSD 3-Clause (`setup.py`, `docs/licensing/`).

## Capabilities and Constraints

- The landing page is a Sphinx page and must build with the existing toolchain.
- No external requests at runtime: no Google Fonts CDN, analytics or third-party embeds.
- Command and module names on the site must match the repository; don't invent flags, options or outputs.
- Open: whether rotifer will be published to PyPI or Bioconda; until then, install copy describes the clone + conda path.
- The site is in English. Landing copy lives in `docs/_data/landing.en.yml` so a Portuguese file can be added later (decided 2026-11-17).

## Brand Commitments

Decided with the owner on 2026-11-17:

- Name: written "rotifer" in the logo and running text. "ROTIFER" and its backronym stay in formal contexts such as the docs' first paragraph.
- Palette: Lagoa. One accent and neutrals, derived from the Move Aqua of LEEP's Ágar palette. Aqua `#2fb3a1` for fills (which take ink text), teal `#0b7869` for accent text and links on light backgrounds, `#4cc9b5` for the accent on dark backgrounds, ink `#101413`, paper `#f7f8f6`, and slightly green-tinted greys.
- Type: Bancada. Chivo for text and headings, Chivo Mono for code, commands, accessions and data. Both are under the SIL Open Font License and must be self-hosted.
- Logo: route 3, "Filtro". A minimal rotifer: two aqua wheels fringed with cilia (the corona), a head that flares like a funnel, an oval trunk with the mastax cut out, and a telescoping foot ending in two toes; next to the wordmark "rotifer" in Chivo Black. The kit is generated by `brand/logo-kit-src/build.py` into `brand/rotifer-logo-kit/` and `brand/rotifer-logo-kit.zip`. These are kept out of git on purpose (local `info/exclude`).
- Lab credit: in the footer and the README, a "Made at" line followed by the psel horizontal lockup (the psel wordmark, a vertical rule, "Protein Structure and Evolution Laboratory" and "ICB · Universidade de São Paulo"). Rotifer otherwise stands as its own project; it carries no psel endorsement near its own logo.
- Landing hero (pinned by the owner): the hero leads with the phrase "Genomics made easy", with rotifer's logo shown small above or below it, over a background of protein sequences slowly passing by.

## Evidence on Hand

- Real code examples in README.md (IPG collection with `entrez.IPGCursor`, assembly reports with `ncbi.assemblies(taxonomy=True)`, debug logging).
- More than 80 command-line tools in `bin/`.
- The existing docs site and its sections.
- The sequences in the hero background must be real protein sequences from public records, and their source accessions should be recorded next to the data. Don't generate random amino-acid strings and present them as proteins.
- There are no testimonials, user counts, citations or benchmarks on hand. Don't invent them.

## Product Principles

1. Honest about what exists. Every tool, command and claim on the site traces back to the repository. Install instructions describe the real install path.
2. Easy first, deep later. "Genomics made easy" is a promise: the first screen and the README answer what it is, what it does for me, and how to start, before any API detail.
3. Data looks like data. Accessions, sequences, commands and tables are shown in their real formats, in the mono face.
4. Standalone, with credit. Rotifer is presented as its own open-source project, crediting the lab that makes it.
5. No external dependencies at runtime. The site works offline from its own files.

## Accessibility & Inclusion

- Text contrast meets WCAG AA in both themes (all Lagoa pairings were checked at 4.5:1 or above).
- The moving sequence background respects `prefers-reduced-motion` (it is static under it), stays behind the text at low contrast, and is hidden from screen readers.
