# Architecture decisions

Architecture decision records (ADRs) are short documents that each
capture one significant decision about ROTIFER: the context, the
choice, the alternatives and the consequences. This page lists them.
The rules for writing one are in {doc}`/contributing/adr`.

No ADRs have been merged yet. The pull request that adds the first
one also adds a table here with the number, decision, status and date
of each ADR, and every later ADR adds its row.
