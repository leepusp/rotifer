# Changelog

All notable changes to ROTIFER are recorded here, newest release first.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and versions follow [Semantic Versioning](https://semver.org).

Entries are not written in this file directly. Each pull request adds a
fragment to `changelog.d/`, and the fragments are collected here when a
release is made. The rules are in the
[contribution docs](https://leepusp.github.io/rotifer/contributing/changelog.html).
